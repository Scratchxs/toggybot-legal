# ToggyBot legal

A tiny static GitHub Pages site. Plain HTML and CSS, with Lenis smooth scrolling and reduced-motion support.

- [Privacy Policy](https://scratchxs.github.io/toggybot-legal/privacy.html)
- [Terms of Service](https://scratchxs.github.io/toggybot-legal/terms.html)

## Edit

Update `privacy.md` or `terms.md`, then run:

```sh
python -m pip install -r requirements.txt
python build.py
```

Commit the Markdown and generated HTML. GitHub Pages publishes `main` from the repository root. No runtime build, framework, analytics, or cookies. Lenis is vendored in `assets/` with its MIT license; Sora is served by Google Fonts.
